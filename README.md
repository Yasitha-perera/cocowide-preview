# COCOWIDE – website design preview

Static front-end preview of the new COCOWIDE website, shared for client review.

- This is a **design preview**, not the live site. The contact form and the review form do not send anything.
- The Blog shows the articles supplied by the client; new articles are written in the admin panel of the full site.
- Pages are plain HTML/CSS/JS – no build step, no analytics or tracking.
- Hidden from search engines (`noindex`, `robots.txt`).
